# 営業ナレッジ Pro — デプロイ手順書

## 搭載機能一覧
| 機能 | 内容 |
|---|---|
| 📝 メモ | 自動保存・タグ付き・全文検索 |
| 📋 タスク管理 | 登録・完了管理 + **AI優先度分析** |
| 📷 OCR | 画像・PDFのテキスト自動抽出（Gemini AI） |
| ✉️ メール | テンプレート下書き作成 + **AI添削** |
| ☑️ チェックリスト | メール送信前・見積送付前・訪問前 |
| 📓 業務日誌 | 日々の業務を毎日1分で記録 |
| 🏆 評価サポート | 目標管理 + **AI自己評価文生成** + 目標設定アドバイス |
| 🤖 AI相談 | 営業専門アシスタントとのチャット |

---

## 必要なもの
- Google アカウント（無料）
- Gemini API キー（無料枠あり）

---

## STEP 1 — Gemini API キーを取得

1. ブラウザで https://aistudio.google.com/app/apikey を開く
2. 「API キーを作成」をクリック
3. 表示されたキーをコピーしてメモ帳に保存

> 無料枠で十分使えます。クレジットカード不要。

---

## STEP 2 — GAS プロジェクトを作成

1. https://script.google.com を開く
2. 「新しいプロジェクト」をクリック
3. 左上のプロジェクト名「無題のプロジェクト」をクリック
4. 「**営業ナレッジ Pro**」に変更して OK

---

## STEP 3 — ファイルを貼り付け

### Code.gs（既存ファイルを置き換え）
1. 左パネルの「コード.gs」をクリック
2. 全選択（Ctrl + A）して削除
3. `gas/Code.gs` の内容をすべて貼り付け
4. 保存（Ctrl + S）

### Index.html（新規追加）
1. 左パネルの「＋」ボタン →「HTML」を選択
2. ファイル名を「**Index**」にする（.html は自動でつく）
3. デフォルトの内容をすべて削除
4. `gas/Index.html` の内容をすべて貼り付け
5. 保存（Ctrl + S）

---

## STEP 4 — スクリプトプロパティを設定（最重要）

1. 上部メニューの「プロジェクトの設定」（⚙️ 歯車アイコン）をクリック
2. 下にスクロールして「スクリプトプロパティ」セクションへ
3. 「プロパティを追加」をクリック
4. 以下を入力：

| プロパティ名 | 値 |
|---|---|
| `GEMINI_API_KEY` | STEP 1 で取得したキー |

5. 「保存」をクリック

---

## STEP 5 — デプロイ

1. 右上「デプロイ」→「新しいデプロイ」をクリック
2. 左の歯車アイコン →「**ウェブアプリ**」を選択
3. 以下の通り設定：

| 項目 | 設定値 |
|---|---|
| 説明 | 営業ナレッジ Pro v2 |
| 次のユーザーとして実行 | **自分** |
| アクセスできるユーザー | **自分のみ**（社内共有なら「組織内全員」） |

4. 「デプロイ」をクリック
5. 「アクセスを承認」→ Google アカウントを選択
6. 「詳細」→「営業ナレッジ Pro（安全ではないページ）に移動」→「許可」

> ※ 自分で作ったアプリなので安全です。Google の確認画面が出るだけです。

---

## STEP 6 — URL をブックマーク登録

デプロイ完了後に表示される **ウェブアプリ URL** をコピーして  
Chrome のブックマークバーに追加 → **毎日すぐ開けます**

## 明日からの使い方

### 毎朝（3分）
1. アプリを開く
2. **タスク** → 今日やることを追加 → 「AI優先度分析」を押す
3. AIが「今日はこの順番でやろう」と教えてくれる

### 仕事中
- **OCR**: 紙の資料・PDFをスマホで撮影 → テキスト抽出してメモ保存
- **メール**: テンプレートを選んで変数を埋めるだけで下書き完成
- **添削**: 大事なメールは送る前にAI添削でスコア確認

### 毎夕（1分）
- **業務日誌** に今日やったこと・成果・課題を記録
- 半年分積み上がると→人事評価の自己評価文がAIで自動生成される

### 評価面談前
- **評価サポート** → 「自己評価を生成」→ 業務日誌から自動生成
- 「目標設定アドバイス」→ 状況を入力→ SMART 目標案を提案

---

## コード変更後の再デプロイ手順

1. コードを編集・保存
2. 「デプロイ」→「デプロイを管理」
3. ✏️ 編集アイコンをクリック
4. バージョンを「**新しいバージョン**」に変更
5. 「デプロイ」

---

## トラブルシューティング

| 症状 | 対処 |
|---|---|
| OCR・AI機能が動かない | スクリプトプロパティの GEMINI_API_KEY を確認 |
| 承認画面が繰り返し出る | デプロイ時に「許可」を最後まで完了させる |
| データが消えた | 右上「📊 データベース」からスプレッドシートを確認 |
| 画面が真っ白 | F12 でコンソールを開きエラーを確認して報告 |
| AIの回答がおかしい | もう一度ボタンを押す（Gemini は確率的なので再試行で改善） |

## データ保存先

初回起動時に Google ドライブに「**営業ナレッジDB**」スプレッドシートが自動作成されます。

| シート名 | 内容 |
|---|---|
| memos | メモ一覧 |
| tasks | タスク一覧 |
| templates | メールテンプレート（デフォルト5種入り） |
| daily_logs | 業務日誌 |
| hr_goals | 人事評価目標（サンプル4件入り） |
| customers | 顧客カルテ（会社情報・担当者・フォロー日管理） |
| meetings | 商談メモ（議事録・AI議事録・フォローアップメール生成） |
| monthly_numbers | 月次数値目標（達成率・AI分析） |
