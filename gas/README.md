## デプロイ手順

詳しくは [DEPLOY.md](./DEPLOY.md) を参照してください。

### 最短手順（15分）

1. [Gemini APIキー取得](https://aistudio.google.com/app/apikey)（無料・カード不要）
2. [script.google.com](https://script.google.com) で新規プロジェクト作成
3. `Code.gs` の内容を貼り付け
4. HTMLファイルを新規作成（名前: `Index`）して `Index.html` の内容を貼り付け
5. スクリプトプロパティに `GEMINI_API_KEY` を設定
6. 「デプロイ」→「ウェブアプリ」→ URLをブックマーク

### 必要なもの

- Google アカウント（無料）
- Gemini API キー（無料枠あり）
- 追加費用: **ゼロ円**

## データ保存先

初回起動時にGoogleドライブに「**営業ナレッジDB**」スプレッドシートが自動作成されます。

| シート名 | 内容 |
|---|---|
| memos | メモ一覧 |

| templates | メールテンプレート（デフォルト5種） |
| daily_logs | 業務日誌 |

| customers | 顧客カルテ |
| meetings | 商談メモ |
| monthly_numbers | 月次数値目標 |
